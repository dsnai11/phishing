# Phishing Awareness Training

## Live Website
🌐 **Live Demo:** https://phishing-rk03.onrender.com

## Project Overview
Phishing Awareness Training is an interactive cybersecurity awareness website designed to educate users about phishing attacks, identify suspicious emails and links, and understand safe online practices.

The project is packaged using the **SCORM 1.2** standard for potential integration with Learning Management Systems (LMS).

## Features
- Interactive phishing awareness training.
- Educational content about phishing attacks.
- SCORM 1.2 package support.
- Browser-based access.
- Cybersecurity awareness learning.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- SCORM 1.2
